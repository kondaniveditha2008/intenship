# Student Score Prediction System

## About the Project

This project predicts a student's examination score based on the number of hours they study.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-learn
* Jupyter Notebook

## Machine Learning Model

The project uses **Linear Regression** to predict student scores.

## Project Files

* `data.py` - Works with the dataset
* `day8_build_model.py` - Builds and trains the machine learning model
* `day9_prediction.py` - Predicts student scores
* `day11_prediction_app.py` - Allows the user to enter study hours and get a predicted score
* `screenshots` - Contains project screenshots

## How It Works

1. Load the student score dataset.
2. Clean and prepare the data.
3. Visualize the data.
4. Train a Linear Regression model.
5. Predict student scores.
6. Evaluate the model.
7. Allow the user to enter study hours and get a prediction.

## Project Goal

The goal of this project is to understand the basic steps of a Machine Learning project using Python.
